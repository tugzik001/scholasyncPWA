# ScholaSync PWA

## How to test the full flow
1. Go to `/pages/school-portal.html` to register a new school.
2. Log in as Principal (using the School Abbr + Master Password).
3. Create a class and generate a Teacher Invite Code.
4. Go to `/pages/teacher-signup.html` and register as a teacher.
5. Log in as Teacher, then go to `/pages/signup.html` to register a student.
